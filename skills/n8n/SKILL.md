# n8n Workflow Automation

MCP server that provides tools and resources for interacting with n8n API. Enables workflow automation and management through the Model Context Protocol.

## When to use
- When you need n8n workflow automation capabilities in your Codex workflow
- When you want to manage n8n workflows via MCP
- See https://github.com/leonardsellem/n8n-mcp-server for full setup instructions
